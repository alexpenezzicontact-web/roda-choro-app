# RODA — Cifras de Choro

Protótipo web/PWA do aplicativo RODA, pensado para leitura harmônica rápida em rodas de choro.

## V1 funcional

- biblioteca e busca;
- cifra por partes e compassos;
- transposição;
- Modo Roda;
- ajuste do tamanho da cifra;
- favoritos;
- repertório “Roda de hoje”;
- editor de músicas;
- marcações estruturais separadas dos acordes;
- persistência local no aparelho;
- suporte offline via service worker.

A biblioteca oficial será adicionada gradualmente depois da conferência das cifras em fontes confiáveis. O protótipo inclui apenas uma cifra-base de desenvolvimento para testar a experiência.
