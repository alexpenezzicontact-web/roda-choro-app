Nova cifra
A cifra é estruturada por partes e compassos. Use uma linha como [A] para criar uma parte e | para separar compassos.
Marcações: depois do acorde use :: para uma indicação estrutural. Ex.: C7 :: D.S. al Coda, F :: 1ª casa, Dm :: fermata, G7 :: vamp. Assim a indicação fica separada do acorde e pode evoluir depois para símbolos gráficos próprios.
